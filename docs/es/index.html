Características de Seguridad Potentes

Todo lo que necesitas para mantener tu entorno de desarrollo seguro.

🔍

Detección de Software

Detecta 21 tecnologías: Node.js, Python, Docker, PostgreSQL, y más — incluyendo gestores de paquetes, bases de datos y herramientas de desarrollo.

🛡️

Análisis de Vulnerabilidades

Consulta las bases de datos OSV, NVD y GHSA para CVEs conocidos en tu stack de software instalado.

🔒

Verificaciones de Hardening

7 verificaciones de seguridad para Linux: estado del firewall, SELinux, configuración SSH, parámetros del kernel y más.

📊

Score de Seguridad

Score ponderado que combina todos los aspectos de seguridad en una métrica (0-100) con recomendaciones accionables.

⚡

Caché Local Inteligente

Datos de vulnerabilidades y versiones cacheados 24h en SQLite local — los escaneos repetidos no usan la red y evitan los límites de las APIs.

📴

Modo Offline

manel sync descarga la base OSV completa localmente — los escaneos con --offline funcionan sin ninguna conexión.

📈

Historial de Escaneos

Cada escaneo se guarda localmente — manel history muestra scores y hallazgos anteriores para seguir tu postura en el tiempo.

🤖

Schema para IA

manel schema genera un JSON que describe cada comando y flag — integra Manel con agentes de IA y automatización.

Cómo Usar Manel

Flujos de trabajo comunes — desde la instalación hasta escaneos 100% offline.

1 Instalación y configuración

terminal 
# Instala globalmente desde npm
npm install -g manel

# Descarga la base de vulnerabilidades offline (una sola vez)
# Detecta los ecosistemas de tu software instalado
manel sync

La primera vez tarda unos minutos (el dump de npm pesa ~200 MB). Re-ejecuta semanalmente.

2 Revisión diaria de seguridad

terminal 
# Vista rápida de las tecnologías detectadas
manel status

# Escaneo completo: vulnerabilidades + hardening + score
manel scan

3 Enfócate en lo importante

terminal 
# Solo hallazgos críticos y altos
manel vulns --severity CRITICAL,HIGH

# Falla el comando (exit 1) si hay algo crítico
# — perfecto para pre-commit hooks y pipelines
manel scan --fail-on critical

4 Exporta e integra

terminal 
# Reporte SARIF para GitHub Code Scanning
manel scan --format sarif --output scan.sarif

# JSON para scripts y dashboards
manel score --format json | jq .data.overall

5 Trabaja 100% offline

terminal 
# Cero peticiones de red — usa la base local sincronizada
manel scan --offline

# Ideal para aviones, redes seguras y CI sin internet
manel vulns --offline --severity CRITICAL

Requiere "manel sync" previo. Los datos locales duran 7 días.

6 Sigue tu postura en el tiempo

terminal 
# Lista tus últimos escaneos con scores y hallazgos
manel history

# Más entradas, formato legible por máquinas
manel history --last 20 --format json

Integración CI/CD

Integra Manel en tus pipelines para verificaciones de seguridad automatizadas en cada commit.

  • Compatible con GitHub Actions
  • Falla builds en vulnerabilidades críticas
  • Sube SARIF a GitHub Code Scanning
  • Funciona con cualquier plataforma CI/CD
.github/workflows/security.yml 
# Ejemplo de GitHub Actions
- name: Security Scan
  run: |
    npm install -g manel
    manel scan --format sarif \
      --output scan.sarif \
      --fail-on critical
